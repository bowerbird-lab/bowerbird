## 2. 数据迁移与覆盖升级基线（P0-08 / P1-13）

- 真机读取旧版 Flutter APK（`com.bowerbird.mobile`）结果：
  - `versionCode = 2002`（来自 Flutter `--split-per-abi` arm64 偏移 `2000 + 2`）
  - `versionName = 1.0.1`，`minSdk = 24`，`targetSdk = 36`
  - 签名摘要：`e30c6e97`（本地 debug keystore）
- 结论：正式替换 `com.bowerbird.mobile` 时，`versionCode` 必须设为 **`>= 2003`**（不能使用当前的 `3`），并使用同一签名证书才能覆盖安装。
- 旧版数据迁移：已在 `MediaBridge.scanLegacyFlutter` + `storage.Local.MigrateLegacyInbox` + `storage.Local.MigrateLegacyShareTags` 实现对 `filesDir/share_inbox/index.json`、`cacheDir/share_inbox/index.json`、`app_flutter/share_inbox/share_tags.json` 的只读复制与幂等迁移；检测到旧 `FlutterSecureStorage` 时在连接页给出不丢收件箱数据的重新配对提示。
